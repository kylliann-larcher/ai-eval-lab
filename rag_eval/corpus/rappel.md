# Rappel

Le rappel (recall, ou sensibilité) mesure la part des vrais cas positifs que le modèle retrouve : vrais positifs / (vrais positifs + faux négatifs).
Un rappel faible veut dire que le modèle rate des cas. C'est la métrique prioritaire quand un cas manqué coûte cher, comme une panne ou une fraude non détectée.
